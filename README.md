# ビエンチャン土地利用マップ

このリポジトリは、ラオスの首都ビエンチャンの土地利用計画を地図で見やすく伝えるためのサイトです。

地図上では、土地利用の区分を色分けして重ね、地形の起伏もあわせて確認できます。専門的な GIS ソフトを使わなくても、ブラウザから開いて、拡大・縮小しながら街の様子を直感的に見ることができます。

## このサイトでできること

- ビエンチャンの土地利用計画を地図上で確認できます
- ズームや移動をしながら、気になる場所を探せます
- 地図上にマウスを重ねると、土地利用区分の名称を確認できます
- 背景地図と地形表現により、場所の雰囲気をつかみやすくなっています

## これまでの経緯

このサイトは、まずビエンチャンの土地利用計画を見られるシンプルな公開サイトとして作られました。その後、地形表現やレイヤの重なり順が調整され、地図の見やすさが少しずつ改善されてきました。

今回の更新では、タイルの読み込み表示が地図操作の邪魔になりにくいように見直しています。読み込み中の案内は控えめにし、地図を拡大したときの印象がより滑らかになるよう整えています。
